# CITIBIG API

پلتفرم یکپارچهٔ سرویس‌های داده و استعلام — با **یک کلید API** به **۱۴۳ سرویس** در ۹ خانواده دسترسی داشته باشید: هویتی، بانکی، قبوض، مخابرات، خودرو، کسب‌وکار، مکان، رسانه و ابزارها.

## چرا CITIBIG API؟

- **یک کلید، همهٔ سرویس‌ها** — بدون چندین پنل و حساب جداگانه
- **REST و JSON** — یکپارچه‌سازی سریع با هر زبانی
- **احراز هویت ساده** — هدر `apikey` در همهٔ درخواست‌ها
- **مصرف شفاف** — هزینه به‌ازای هر فراخوانی موفق

## کاوش API

مرجع کامل تعاملی (هر ۱۴۳ اندپوینت با درخواست نمونه) در بخش **API Reference** همین سایت در دسترس است — تغذیه‌شده مستقیم از Scalar Registry، و نمونه‌های SDK هم خودکار در هر اندپوینت نمایش داده می‌شوند.
