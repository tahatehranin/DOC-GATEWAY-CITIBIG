# احراز هویت

همهٔ درخواست‌ها به CITIBIG API باید هدر `apikey` را داشته باشند.

| مورد | شرح |
|---|---|
| نام هدر | `apikey` |
| محل ارسال | هدر HTTP همهٔ درخواست‌ها (GET و POST) |
| محدودهٔ دسترسی | کاتالوگ سرویس‌های پلن شما |

## مثال

```bash
curl -X POST "http://2.144.22.190:9080/apiir/sw1/IbanInfo" -H "apikey: YOUR_API_KEY"
```

## امنیت کلید

- کلید را فقط از سمت سرور ارسال کنید — در کد کلاینت (مرورگر/اپ موبایل) قرار ندهید.
- کلید را commit نکنید؛ از متغیر محیطی استفاده کنید.
- در صورت لو رفتن کلید، از CITIBIG درخواست تعویض کنید.

## پاسخ‌های احراز هویت

| پاسخ | معنی |
|---|---|
| `{"message":"Missing API key in request"}` | هدر ارسال نشده |
| `{"message":"Invalid API key in request"}` | کلید نامعتبر |
