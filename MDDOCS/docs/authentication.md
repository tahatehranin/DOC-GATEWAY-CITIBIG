# :material-key-variant: احراز هویت

تمام درخواست‌ها به CITIBIG API باید هدر `apikey` را داشته باشند. کلید API از CITIBIG دریافت می‌شود.

## ارسال کلید

```text
apikey: YOUR_API_KEY
```

| مورد | شرح |
|---|---|
| نام هدر | `apikey` |
| محل ارسال | هدر HTTP همهٔ درخواست‌ها (GET و POST) |
| محدودهٔ دسترسی | کاتالوگ سرویس‌های پلن شما |

!!! note "یک کلید، چند سرویس"

    کلید شما به **همهٔ سرویس‌های فعال پلن شما** دسترسی دارد؛ برای هر سرویس نیازی به کلید جداگانه نیست.

## امنیت کلید

- کلید را در کد سمت کلاینت (مرورگر، اپلیکیشن موبایل) قرار **ندهید**؛ فقط از سمت سرور ارسال کنید.
- کلید را در مخازن کد commit نکنید؛ از متغیر محیطی استفاده کنید.
- در صورت لو رفتن کلید، از CITIBIG درخواست تعویض کلید کنید.

## پاسخ‌های احراز هویت

| پاسخ | معنی | اقدام |
|---|---|---|
| `{"message":"Missing API key in request"}` | هدر `apikey` ارسال نشده | هدر را اضافه کنید |
| `{"message":"Invalid API key in request"}` | کلید نامعتبر است | مقدار هدر را بررسی کنید |
